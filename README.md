# Time Management

A simple personal task manager that runs in your web browser.

## Features

- Add tasks with a title, due date, priority (low / medium / high) and notes
- Mark tasks as done, edit them, or delete them
- Filter by **Today**, **Upcoming**, **Overdue** or **Done**
- Search tasks and sort by due date, priority or newest
- Overdue tasks are highlighted
- Export your tasks to a file and import them again (for backup or moving to another device)
- Works on phones and computers, with automatic dark mode

## How to use it

Open `index.html` in any web browser. That's it — no installation needed.

Your tasks are saved in the browser you use, on that device. Use **Export** to keep a backup
or to move your tasks to another browser or device.

## Files

- `index.html` — the page layout
- `style.css` — the look and feel
- `app.js` — the task logic and saving
